Unsupervised zero-shot unknown radiation source detection: these four design principles are crucial! Paper title: Design Principles for Unsupervised Self-Supervised Unknown Radiation Source Detector
Abstract: In a competitive wireless environment, achieving reliable situational awareness requires the ability to detect unauthorized or malicious radiation sources without prior knowledge of characteristic features. Existing research on unknown radiation source detection (UED) and recognition is limited by reliance on labeled/proprietary datasets, unrealistic assumptions (such as all samples transmitting identical information), and a lack of systematic evaluation across architectures and design dimensions.
This paper clarifies the design dimensions based on machine learning for unknown radiation source detection, proposes a structured workflow that guides related research and end-to-end unlabeled unknown radiation source detection design, which includes four core components: data modalities, feature learning modules, machine learning methods, and decision modules. With this workflow, this paper explores the design principles of unknown radiation source detection in two typical scenarios: SMS and DMS, obtaining several key conclusions: under more realistic SMS scenarios, the 2D constellation data modality can improve the ROC-AUC metric by up to 20 percentage points compared to traditional raw I/Q representations; the Kolomogrov-Arnold network (KANs) can provide interpretable feature representations and perform equally well with convolutional neural networks (CNNs) in both scenarios; optimal configurations for different SMS scenarios involve combining singular value decomposition (SVD) initialized KANs with deep clustering methods and 2D constellation modalities, yielding an ROC-AUC improvement of up to 20 percentage points compared to standard KANs under the same workflow; through analysis of the decision module, the optimal number of clusters suitable for environments with varying known radiation source counts was determined.
Introduction: The management and operation of wireless communication networks increasingly rely on situational awareness and spectrum awareness to dynamically adapt to environmental changes and user/application demands. Spectrum awareness and network security are also core research directions for future open radio access networks (O-RAN). Related technologies can be applied in interference management, compliance regulation, and spectrum optimization, building an efficient spectrum-aware wireless communication network with modulation and technology classification techniques.
One of the core challenges in spectrum perception is to reliably detect and identify radiation sources within the communication range, relying on robust signal processing techniques and increasingly employing advanced machine learning methods. In the field of device recognition, the research community has divided it into two complementary processes: Specific Emission Source Identification (SEI) based on the assumption of a closed set, using unique signal distortion characteristics of devices to identify known radiation sources, suitable for scenarios in network security authentication; Unidentified Emission Source Detection (UED) based on an open set assumption, identifying signals deviating from the characteristics of known radiation sources, detecting new, forged, or adversarial radiation sources, avoiding misclassification by specific emission source identification, forming a closed-loop detection and identification system to ensure situational awareness and network security in dynamic wireless environments.
Current research predominantly focuses on the problem of closed-set classification, relying on labeled data to construct supervised learning models that perform well in recognizing known devices. However, in real open scenarios, the continuous emergence of new radiation sources makes it difficult to obtain labeled data, rendering supervised learning inapplicable. Open-set problems can be divided into few-shot and zero-shot learning. The former still follows the supervised evaluation paradigm but with very few labeled samples, while the latter requires detecting radiation sources that have never appeared during training.
The study found that developing a radiation source identification system based on device-specific signal distortions requires systematic consideration of various design choices in the application scenario, including problem formulation, data modalities, feature learning, and machine learning methods: The choice of data modalities affects the final performance of the model and the complexity of the feature learning module; the design of the feature learning module is related to performance, complexity, and interpretability. Although classic architectures such as Convolutional Neural Networks (CNN) and Transformer perform well, designing specialized models for radio frequency signals can reduce complexity. At the same time, the issue of interpretability in deep learning models has not been effectively resolved, and security-related applications have clear requirements for the interpretability of radiation source detection and recognition.
For zero-shot scenarios, self-supervised learning (SSL) is the most applicable machine learning method, which generates supervised signals through data operations such as pseudo labeling, data augmentation, and reconstruction without human annotation, achieving good generalization and meeting the practical deployment needs of open-set radiation source detection.
This paper clarifies seven major design dimensions for unknown radiation source detection based on machine learning, focusing on zero-shot scenarios without prior information, proposing an end-to-end unlabeled unknown radiation source detection structured workflow with four core components. It also conducts research in two transmission scenarios based on two data modalities, three feature learning methods, and three self-supervised learning methods, while open-sourceting relevant code, filling several gaps in existing research.
Method overview: This paper focuses on the zero-shot self-supervised unknown radiation source detection problem, constructs a structured workflow that includes data modalities, feature learning module, machine learning methods, and decision module, and combines evaluation metrics and model interpretability analysis to form a complete unknown radiation source detection system. The specific method design is as follows:
Problem and Scenario Definition: Based on orthogonal frequency division multiplexing (OFDM) modulation, the radio fingerprint characteristics of the radiation source signal are decomposed into clean signals and device-specific distortion signals (radio fingerprints), and two transmission scenarios are defined: the same message scenario (SMS) only extracts the pilot code from the signal, with consistent transmission content from each radiation source, making the task relatively easy; the different message scenario (DMS) obtains random frame data, where the clean signal is unknown, making the task more realistic and challenging. The detection of unknown radiation sources is defined as a zero-shot self-supervised learning task, constructing a composite model composed of embedding functions and detection functions to achieve classification judgment from raw radio frequency signals to "known/unknown".
2
Data Modality: Research two representation methods for radio frequency signals, one is traditional raw I/Q data, which splits complex numbers into co-phase and orthogonal dual-channel inputs; the other is 2D constellation diagram modality, which converts the raw I/Q data into time-invariant heatmap forms through normalization and grid statistics, reducing the interference of semantic information on radio fingerprint extraction, adaptable to different message transmission scenarios.
3
Feature Learning Module (FLM): Select CNN and explainable Kolmogorov-Arnold network (KANs) as core feature extraction architectures, while PCA is introduced as a lightweight baseline. For CNN, 1D/2D architectures are designed respectively to adapt to raw I/Q and 2D constellation diagram modality; KANs replaces traditional activation functions with learnable spline functions to achieve global interpretability of the model; to improve performance, linear layers with SVD initialization are introduced to both architectures, enhancing feature extraction capabilities by aligning with the linear characteristics of radio fingerprints.
4
Machine Learning Methods: Three mainstream self-supervised learning methods are selected to train the feature learning module, namely deep clustering (DC), generating pseudo labels through alternating clustering and updating the model with classification training; autoencoder (AE), learning signal features through reconstruction loss; contrastive learning (CL, SimCLR), learning discriminative features through generating positive/negative pairs with cross-entropy loss.
5
Decision Module (DMM): Adopts a robust outlier detection method for clustering, training is completed through K-means to cluster the training features into C clusters. During inference, the distance of test samples to the nearest cluster center is calculated, and compared with the distribution of distances for training samples. If it exceeds the set quantile, it is determined as an unknown radiation source, achieving general decision-making independent of feature learning modules and machine learning methods.
6
Experiment and Evaluation: Experiments are conducted based on two public datasets, WiSig (SMS) and ORACLE (DMS), using ROC-AUC, normalized mutual information (NMI), F1 score to evaluate model detection and clustering performance. At the same time, the model parameters and floating-point operations (FLOPs) are counted to measure computational complexity; cross-validation is used to divide the training/test set, exploring the performance of different component combinations, and analyzing the model's interpretability (CNN uses LIME to achieve local interpretability, KANs has inherent global interpretability).
Conclusion: This paper comprehensively analyzes the design space of unknown radiation source detection. Combining SMS and DMS two transmission scenarios, from four core dimensions of data modality, feature learning module, machine learning method, and decision module, explores the impact of various design choices on model performance. Four major conclusions are drawn:
1
In the real-world different message transmission scenarios, the 2D constellation data modality can reduce the interference of semantic information by up to 20 percentage points compared to traditional raw I/Q data, making it the optimal data modality choice in this scenario.
2
The Kolomogrov-Arnold network (KANs) as an explainable network architecture, achieves performance comparable to "black box" convolutional neural networks (CNNs) under two transmission scenarios, providing a new choice for radiation source detection that balances performance and interpretability.
3
Under different message transmission scenarios, the optimal configuration for unknown radiation source detection is SVD-initialized KANs + deep clustering method + 2D constellation map modality. This configuration significantly improves the ROC-AUC indicator by up to 20 percentage points compared to standard KANs under the same workflow.
4.
By conducting a sensitivity analysis on the decision module, the optimal number of clusters was determined: the number of clusters should match the known number of radiation sources. The optimal number of clusters for the WiSig dataset (6 radiation sources) is 80, and for the ORACLE dataset (16 radiation sources), it is 200. Once this value is reached, the model performance tends to stabilize.
Overall, by integrating KANs-based feature extractors with interpretable representations into the decision and feature learning modules, the proposed unknown radiation source detection model effectively generalizes to unseen radiation sources and varying signal conditions. It achieves the level of generalization not achieved in existing studies, providing systematic guidance principles for the practical design and deployment of zero-shot self-supervised unknown radiation source detection.
